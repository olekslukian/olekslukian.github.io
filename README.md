# olekslukian.github.io

Personal portfolio and landing page for Oleksandr Lukianov.

## Features

- Minimalistic, clean design
- Fully responsive
- Dark mode support
- Fast and lightweight

## Getting Started

Simply open `index.html` in your browser, or visit https://olekslukian.github.io

## Deployment

This site is hosted using GitHub Pages. Push changes to the `main` branch to deploy.
